# 🏏 IPL Win Prediction Engine

An end-to-end Machine Learning project that predicts IPL match outcomes with **74%+ accuracy** using XGBoost, Random Forest, and SHAP explainability — trained on 19 seasons of IPL data (2008–2026).

## 🚀 Live Demo
> Coming soon

## 🧠 ML Stack
- **XGBoost** — primary model (74.2% accuracy)
- **Random Forest** — ensemble comparison
- **Logistic Regression** — baseline
- **SHAP** — model explainability
- **Pandas + NumPy** — data processing

## 🌐 Web App
- **Next.js + TypeScript** — frontend
- **FastAPI** — prediction API backend
- **Chart.js** — win probability visualizations

## 📊 Dataset
- 19 IPL seasons (2008–2026)
- 984 matches
- Ball-by-ball data
- Source: Kaggle
